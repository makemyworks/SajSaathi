# Database (MongoDB Atlas, database `saj_saathi`)

Ids are 24-character hex strings generated by the app. Money is integer **paise**. Dates are UTC; display is Asia/Kolkata.
Indexes are created automatically on first API start and by `npm run setup` (`lib/server/mongo-repo.ts`).

| Collection | Holds | Key indexes |
|---|---|---|
| `users` | customers, partner owners, admins (`role`, `adminRole`), scrypt password hash, consents, MFA secret, locale, favourites | unique `email`, unique `phone` (partial) |
| `sessions` | live logins (revocable) | `userId`; TTL on `expiresAt` |
| `providers` | partner businesses / individuals: application status, address, branches, service area, hours, holidays, answers, credentials (labels+doc ids), gallery, ratings, commission exception, featured | unique `slug`; `status+categoryIds+address.city`; `serviceArea.pins`; `address.pin` |
| `staff` | team members & which services they do | `providerId` |
| `services` | price, duration, mode, add-ons, packages, staff | `providerId+active`, `categoryId` |
| `categories` | verticals with all configurable rules and forms | unique `slug` |
| `bookings` | the booking, server price breakdown, status, payment status, history | unique `ref`; `providerId+start`; `customerId+start`; `status+start` |
| `slot_locks` | one row per 5-minute unit per staff/provider for holding bookings | **unique `resource+unit`** (prevents double booking); `bookingId` |
| `blocks` | partner-blocked times | `providerId+start` |
| `payments` | Razorpay order/payment, status, refunds, receipt no. | unique `gatewayOrderId`; `bookingId` |
| `refunds` | refund requests and gateway refund ids | `bookingId`, `status` |
| `webhook_events` | processed gateway event ids (idempotency) | unique `eventId`; TTL 90 days |
| `reviews` | one per completed booking | unique `bookingId`; `providerId+status+createdAt` |
| `coupons`, `coupon_redemptions` | coupons and per-booking use | unique `code`; unique `couponId+bookingId` |
| `notifications` | in-app inbox + per-channel delivery status | `userId+createdAt` |
| `push_subscriptions` | browser push endpoints | — |
| `tickets` | support & safety tickets with messages | `userId+updatedAt`, `status` |
| `documents`, `files` | private verification docs (metadata / bytes) and public photos | `providerId` |
| `addresses` | customers' saved addresses | `userId` |
| `audit_events` | who did what (admin actions, document views, logins, exports) | `at`, `entity+entityId` |
| `rate_limits` | login/booking throttles | unique `key+window`; TTL |
| `settings` | `platform` (fees, commission, support, maintenance text), `admin_roles` overrides | — |
| `feature_flags` | memberships, referrals, future modules, maintenance, online payments | — |
| `countries`, `states`, `cities`, `pincodes`, `territories` | location management (India + 36 states/UTs seeded) | — |
| `plans`, `memberships`, `payouts`, `referral_programs`, `promotions`, `campaigns` | commercial configuration and records | — |
| `templates`, `whatsapp_templates` | message template overrides | — |
| `pages`, `faqs`, `seo_entries`, `languages` | content management | — |
| `job_posts`, `courses`, `products` | future modules (feature-flagged; no checkout) | — |
| `deletion_requests` | account deletion queue | — |

### Backups
Use Atlas continuous backup (M10+) or scheduled snapshots. Test a restore before launch.
